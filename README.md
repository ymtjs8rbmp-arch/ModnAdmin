# Community Signup (simple version)

This simplified GitHub Pages version contains only `index.html` and `README.md`.

## Publish it with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `README.md` to the repository's top/root level.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## What this version does
- Animated duck mascot and fox helper with preset answers
- Tier 1 Mod / Tier 2 Admin selection
- New applicants are advised to apply for Mod first
- Username and age range choices
- Thank-you screen after submit

## Important limitation
This is a static site. Submitting the form opens the visitor's default email app with the application details prefilled and addressed to `daviolvcass@gmail.com`. The visitor must press Send; if they do not have an email app configured, this may not work. The destination address is visible in the page source. This method does not automatically send or store applications.

Because an under-13 age option is included, review child-privacy requirements before collecting submissions from children. Consider disabling that option unless you have a compliant process.
