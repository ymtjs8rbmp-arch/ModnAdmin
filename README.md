# Community Signup Website

A static signup page with tier selection, age range, Yapper username, animated duck, and fox FAQ helper.

## Automatic email submissions

Applications are sent to **daviolvcass@gmail.com** using FormSubmit's AJAX endpoint, so applicants do not need to open their email app.

**One-time setup required:**
1. Publish the site (or test it from a local web server).
2. Submit one test application.
3. Check `daviolvcass@gmail.com` for FormSubmit's activation/confirmation email and follow its instructions. Check Spam if needed.
4. Submit another test application and confirm it arrives. Until the address is activated, automatic delivery may not work.

FormSubmit is a third-party service, so review its terms/privacy information before collecting real applications. Do not collect sensitive information. Since the form offers an “Under 13” option, check applicable child-privacy requirements before publishing or collecting submissions from children.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Open the Pages URL after deployment finishes.

No `package.json` or build step is required.
